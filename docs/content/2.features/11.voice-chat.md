Turn on **Voice chat** in a server's settings (or in the create wizard) and
MCSM installs [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat)
from Modrinth and wires up its network port, so players can talk without any
manual setup.

Works on Paper, Fabric, Forge, NeoForge and CurseForge modpack servers.

## How the port works

Voice audio travels over **UDP**, which the Infrarust proxy can't forward. So
each server with voice chat gets its own UDP port published directly on the
Docker host:

- **Automatic** — leave the port empty and MCSM picks the first free one from
  `24454` upwards, skipping ports other MCSM servers already use.
- **Manual** — enter a port yourself; MCSM rejects ports another server is
  already using.
- **Stable** — the port is stored with the server, so saving settings,
  enabling BlueMap or switching variants keeps it.

MCSM writes the port into the plugin's `voicechat-server.properties` before the
server starts and leaves every other setting in that file alone.

Players need the Simple Voice Chat mod in their client. It connects on its own
after joining; the server's **Overview** shows the address and port.

::warning
Docker publishes ports past host firewalls like UFW, so the voice port is
reachable from the internet as soon as it's enabled. If your provider runs a
firewall in front of the host (e.g. a Hetzner Cloud Firewall), allow the port
as **UDP** there.
::
