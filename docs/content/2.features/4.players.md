The **Players** tab manages who can join your server and what they can do —
no commands required.

## Add operators and whitelist players

Look players up by username — their UUID and skin avatar are resolved from
Mojang automatically, so you always add the right account:

- **Operators** — grant or revoke op status.
- **Whitelist** — manage the allowed players.

The lists shown are the server's own `whitelist.json` and `ops.json`, so they
always match what the server enforces. On a running server changes apply
immediately (via RCON); on a stopped one they're saved to the files and apply
on the next start. Either way they survive restarts and configuration edits.

The operators and whitelist you pick when creating a server only seed a new
world.

Managers can also switch the whitelist on or off (live, no restart) and
toggle **Enforce Whitelist**, which kicks connected players that are removed
from it. Minecraft reads enforcement only on startup, so changing it on a
running server restarts it after a confirmation.

## Moderate online players

When the server is online, the tab lists everyone currently playing, with
their avatar and name. From there you can:

- **Kick** a player off the server,
- **Ban** them (and unban later).
